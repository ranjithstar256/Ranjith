## Integrity vs. identity

The SHA-256 hashes can detect accidental or malicious modification of files relative to this manifest. They do **not**, by themselves, prove the author's legal identity.

A GitHub commit made through the author's connected GitHub account provides an additional historical account-level provenance trail. For stronger personal authentication, the author can later countersign this capsule using a cryptographic key that only he controls.
